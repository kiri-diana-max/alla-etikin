# Алла Усынина · ЭтиКин
Самостоятельный статический сайт. Разделы: об Алле, шесть тренингов, три игры, книга, вопросы, контакты. Документы находятся в privacy.html, consent.html и offer.html.

Контакты только через Telegram и MAX. «Присоединиться» — неактивная заглушка.
Видео: 7 секунд, без аудиодорожки; запуск в области видимости, пауза, поддержка reduced-motion. Исходник — предоставленный ролик «Жесты увереннного человека.MOV».

## Публикация и перенос
GitHub Pages публикует корень ветки main. На обычный статический хостинг загрузить файлы из архива alla-etikin-site.zip. Сборка, Tilda, база данных и серверные функции не нужны.
После выбора домена заменить текущий адрес GitHub Pages в canonical, Open Graph, Schema.org, robots.txt, sitemap.xml и адресах сайта в документах. Внутренние ссылки и ресурсы относительные.

## Материалы
Тексты программ переработаны по предоставленному прежнему сайту. Цены и формы оплаты не перенесены. Юридические документы перенесены с изменением адреса сайта; их редакция 15.04.2025 сохранена. Перед окончательным запуском требуется проверить соответствие документов новой схеме работы (сейчас без форм и онлайн-оплаты).
