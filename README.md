# Алла Усынина · ЭтиКин
Адаптивный лендинг: этикет, самопрезентация, невербальное общение.
Статический сайт без сборки. Публикация через GitHub Pages.
Контакты — кнопки Telegram и MAX. Номер телефона и vCard удалены.
Telegram: текст передаётся в ссылке. MAX: копирование сообщения и переход по ссылке на профиль.
«Присоединиться» — неактивная заглушка; ссылку на канал нужно добавить позднее.
SEO: title, description, canonical, Open Graph, sitemap и Schema.org JSON-LD (Person, Organization, WebSite, WebPage, Book).
Источник реквизитов и программ: https://etikin.ru/.
Цитата: Алла Усынина, «Сила впечатления», АСТ, 2024, с. 15 (PDF-разворот 8). PDF целиком не публикуется.
